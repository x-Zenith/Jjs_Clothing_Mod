# Jjs Clothing Mod

Custom clothing for **skate.** / **ReSkate**. Adds new wardrobe items you can equip in
Create-A-Skater.

> **ReSkate / Offline only.** This is a ReSkate Studio native patch. Only load it when
> launching through ReSkate (Offline Skate). Do **not** run it under normal online /
> anti-cheat skate. — modified game data on an online session can get you banned.

## Install (manual)

This mod installs as a **folder**, not through an auto-loader. The Thunderstore mod manager
won't place it for you, so install it by hand:

1. Download and unzip this package.
2. Copy the **`Jjs_ClothingMod`** folder into your ReSkate **mods** folder
   (the folder ReSkate reads patches from — the same place your other ReSkate Studio mods live).
3. Make sure the mod is **enabled** in ReSkate's mod list / launcher.
4. Launch the game **through ReSkate (Offline)**.
5. The new clothing appears in **Create-A-Skater**.

## Uninstall

Remove (or disable) the `Jjs_ClothingMod` folder from your ReSkate mods folder.

## Compatibility

- Built against skate. game data `sha256 fbce74d5…b8b8f9`. If a game update changes that
  build, the patch may need rebuilding in ReSkate Studio.
- May conflict with other mods that patch the **same** wardrobe/items data. Load one at a time
  if items don't show up.
